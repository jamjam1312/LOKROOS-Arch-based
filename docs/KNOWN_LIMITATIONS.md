# Known limitations — 0.1.0-alpha.22 source candidate

- This is an alpha for test machines. Secure Boot and guaranteed dual-boot are not supported.
- LUKS1 encryption is available but remains experimental until BIOS and UEFI installs have completed the full reboot test. LUKS2/Argon2 is intentionally deferred because stock GRUB compatibility needs more integration work.
- The automatic Calamares layout erases the selected disk. The default partition choice is intentionally empty so the user must choose explicitly.
- NVIDIA's packaged open kernel module supports Turing / GTX 16 / RTX 20 and newer. Older NVIDIA hardware stays on Nouveau; no legacy AUR driver is installed.
- Plasma is Wayland-only. X11 applications run through XWayland, but there is no Plasma X11 login session.
- Hyprland is an optional secondary Wayland session, not a second full LOKRO desktop. Plasma remains the supported default and some KDE settings only affect Plasma.
- Design packs are user-scoped and intentionally limited to declarative settings, KDE color files and ordinary wallpaper images. The Store accepts only reviewed packs with an immutable HTTPS URL and exact SHA-256; arbitrary remote packs, QML themes, scripts and executables remain blocked. Cursor and look-and-feel identifiers must already be installed by a trusted package.
- LOKRO Media is a branded launcher and file-association layer around unmodified VLC, not a fork or a new decoding engine. VLC retains its own interface and license.
- The Link Installer cannot safely turn every Linux download URL into an installable application. It accepts only HTTPS Flatpak refs/bundles, signature-verifiable Arch packages and AppImages; scripts, DEB/RPM packages and archives are rejected intentionally.
- KRunner and Baloo approximate Everything-style search, but Linux permission boundaries still apply and filename results become complete only after initial indexing.
- GRUB runs `os-prober` for discoverable systems, but encrypted Windows volumes, BitLocker, Fast Startup and mismatched BIOS/UEFI modes can prevent detection. Dual boot remains an alpha feature.
- The LOKRO Hub contains only the Twitch-confirmed public Twitch, TikTok and Discord destinations. It has no SSO, account integration, private API or verified standalone website yet.
- Ollama support is an optional large download. AMD ROCm compatibility depends on the exact GPU; CPU fallback is always available but can be slow.
- LOKRO packages are delivered as checksummed GitHub Release archives. They do not yet have a dedicated offline signing key, so unattended LOKRO package installation stays disabled by default. Arch packages continue to use signed official mirrors.
- Kernel packages can be installed while the old kernel runs and its modules are retained, but the new kernel still requires a reboot to become active.
- The repository contains build and VM smoke infrastructure, but real AMD/NVIDIA and multi-monitor results must be recorded by a human before publishing an image.
- The online image installs a minimal Plasma/Firefox system without internet, but selected office or gaming downloads are skipped; the offline image is the complete recovery-safe variant.
- Steam and Minecraft are proprietary. The optional bundle prepares drivers and launchers, but game assets, accounts and online authentication are never embedded in the ISO.
- Automatic install-alongside depends on the existing filesystem and free space. BitLocker, Windows Fast Startup and unusual storage controllers can prevent safe resizing; a verified backup is mandatory.
- ARM is a separate future port based on Arch Linux ARM and cannot reuse the x86_64 Archiso image.
- GitHub release files must each remain below 2 GiB. The larger ISO images are published as numbered raw parts and must be reassembled and checksum-verified before use.
