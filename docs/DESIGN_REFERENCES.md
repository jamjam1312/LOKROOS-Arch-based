# LOKRO visual direction

The user supplied visual references on 16 October 2026 for a later branding
pass. They are references, not redistributable source assets, until authorship
and licensing are documented.

The intended direction is monochrome and high contrast: black and white fields,
halftone cloud or nebula textures, small dot patterns, fine geometric corner
marks, restrained targeting/grid symbols and the angular LOKRO wordmark. The
boot menu, login screen and desktop should share those cues without reducing
text readability or accessibility.

This alpha-15 milestone deliberately fixes installer, Store and Plasma runtime
bugs first. It does not copy or derive boot artwork from the supplied images.
