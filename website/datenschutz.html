RECHTLICHES / DATENSCHUTZ

Datenschutz

LOKRO OS verwendet keine eigene Webanalyse, keine Werbetracker und kein Kontaktformular. Technische Verbindungsdaten entstehen dennoch beim Hosting und beim Abruf von GitHub-Inhalten.

KURZFASSUNG

Die Projektseite speichert selbst keine Besucherprofile. ISO-Dateien werden im Browser ausschließlich lokal verarbeitet. Beim Seitenaufruf, bei der Release-Abfrage und beim Download erhält GitHub technisch erforderliche Verbindungsdaten.

1. Verantwortlicher

Verantwortlich für die Verarbeitung durch das LOKRO-OS-Projekt ist der im Impressum genannte Anbieter.

E-Mail: support@lokro.dev

Hinweis: Vollständiger bürgerlicher Name und ladungsfähige Anschrift des Verantwortlichen müssen noch ergänzt werden.

2. Hosting über GitHub Pages

Diese Website wird als GitHub Pages-Seite aus einem öffentlichen Repository ausgeliefert. Beim Aufruf verbindet sich dein Browser mit Systemen von GitHub. Dabei können insbesondere IP-Adresse, Datum und Uhrzeit, angeforderte Seite, Referrer, Browser-, Geräte- und Betriebssysteminformationen sowie technische Sicherheits- und Leistungsdaten verarbeitet werden.

Die Verarbeitung dient der sicheren und zuverlässigen Bereitstellung der Website. Soweit das LOKRO-OS-Projekt hierfür verantwortlich ist, stützen wir sie auf Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse liegt in Betrieb, Stabilität und Schutz der Projektwebsite. GitHub verarbeitet bestimmte Daten außerdem in eigener Verantwortung.

Weitere Informationen: GitHub General Privacy Statement.

3. GitHub API und Downloads

Die Download-Seite fragt beim Laden die öffentliche GitHub API nach dem neuesten LOKRO-OS-Release ab. Dabei wird deine IP-Adresse technisch an GitHub übermittelt. Ist die API nicht erreichbar, verwendet die Seite fest hinterlegte Release-Daten.

Wenn du ISO-Teile, Prüfsummen, Quellcode oder Skripte öffnest oder herunterlädst, stellt dein Browser eine direkte Verbindung zu GitHub beziehungsweise dessen Release-Infrastruktur her. Es gelten zusätzlich die Datenschutzhinweise von GitHub.

4. Lokales Zusammensetzen der ISO

Ausgewählte ISO-Teile werden mit der File System Access API lokal auf deinem Gerät gelesen, zusammengesetzt und mittels SHA-256 geprüft. Die ausgewählten Dateien, ihre Inhalte und das fertige Abbild werden nicht an LOKRO OS oder einen eigenen Server übertragen.

Auch das interaktive Zeichenraster, Designumschalter und die Skripterzeugung laufen lokal im Browser.

5. Cookies, Tracking und lokale Speicherung

Der von LOKRO OS bereitgestellte Seitencode setzt keine eigenen Cookies, verwendet keine eigene Webanalyse, bindet keine Werbenetzwerke ein und legt keine Besucherprofile an. Die Seite speichert derzeit auch keine Einstellungen in Local Storage oder Session Storage.

GitHub kann im Rahmen seiner eigenen Dienste technisch erforderliche Informationen oder Cookies verarbeiten. Einzelheiten beschreibt GitHub in seiner oben verlinkten Datenschutzerklärung.

6. Kontakt per E-Mail

Wenn du an support@lokro.dev schreibst, verarbeiten wir deine Absenderadresse, Nachricht und freiwillig mitgeteilte Angaben, um dein Anliegen zu bearbeiten. Rechtsgrundlage ist – je nach Inhalt – Art. 6 Abs. 1 lit. b oder lit. f DSGVO. Unser berechtigtes Interesse ist die Beantwortung von Projekt- und Supportanfragen.

Nachrichten werden gelöscht, wenn sie für die Bearbeitung nicht mehr erforderlich sind und keine gesetzlichen Aufbewahrungs- oder Nachweispflichten entgegenstehen. Der technische E-Mail-Anbieter kann Verbindungs- und Metadaten nach seinen eigenen Bedingungen verarbeiten.

7. Speicherdauer und Empfänger

LOKRO OS betreibt keine eigene Besucherdatenbank und erhält von GitHub Pages keine eigene Liste einzelner Seitenbesucher. Für von GitHub in eigener Verantwortung verarbeitete Daten gelten die dort genannten Speicherfristen. Empfängerkategorien sind Hosting- und Infrastrukturprovider sowie – bei E-Mail-Kontakt – der technische E-Mail-Anbieter.

8. Deine Rechte

Unter den gesetzlichen Voraussetzungen hast du insbesondere Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerspruch. Du kannst dich außerdem bei einer Datenschutzaufsichtsbehörde beschweren.

Anfragen zur Verarbeitung durch LOKRO OS sendest du an support@lokro.dev. Für Verarbeitungen, bei denen GitHub selbst Verantwortlicher ist, wende dich bitte an GitHub.

9. Automatisierte Entscheidungen und Änderungen

LOKRO OS führt über diese Website keine automatisierte Entscheidungsfindung und kein Profiling durch. Wir aktualisieren diese Erklärung, wenn sich Hosting, Funktionen oder Datenflüsse ändern.
