# LOKRO Chamfer

This reviewed built-in pack enables the trusted native QML chamfer surfaces in
LOKRO Settings. The small, regular and large cuts use 10, 18 and 28 pixels,
matching the corner specification supplied by Erik / LOKROGAMER.

The pack is declarative. It contains no JavaScript, QML payload, executable
file or copied website asset. KDE and third-party application controls remain
under their own installed widget styles.
