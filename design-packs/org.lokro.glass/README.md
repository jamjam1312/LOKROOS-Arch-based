# LOKRO Glass

This first-party pack is original LOKRO OS artwork and configuration under
CC BY-SA 4.0. Its visual direction uses translucent black surfaces, thin white
focus lines and cool neutral highlights. The public LOKRO network website was
reviewed as a visual reference, but its repository currently declares no
license; no website asset, CSS rule or source file is copied into this pack.

Visual direction: Jamie Milo Cürten and Erik / LOKROGAMER. Implementation:
LOKRO OS contributors with help from ChatGPT / OpenAI Codex.
