# LOKRO design artwork provenance

The Eclipse and Lunar wallpaper files are original project artwork created on
19 October 2026 with OpenAI's built-in image-generation tool, using the
user-supplied LOKRO posters only as visual-style references. The generated
wallpapers deliberately contain no copied poster text, logo or exact layout.

Generation mode: built-in image generation. The prompts requested a new 16:9
desktop wallpaper with monochrome halftone clouds, sparse technical marks,
dots and slash motifs; one predominantly black variant and one predominantly
white variant; calm areas for desktop readability; and no words, logos,
signatures or watermarks.

Project artwork is distributed under CC BY-SA 4.0.
